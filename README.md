# USMC Admin Tools

Offline-capable tools for the admin work Marines do every week. No accounts, no data collection, PDF export, works on a phone.

**[Open the tools](https://jeranaias.github.io/usmc-tools/)**

| Tool | What it does |
| --- | --- |
| PFT/CFT Proctor | Run and score a PFT or CFT |
| Pros & Cons Generator | Draft pros and cons marks with justification |
| Page 11 Generator | Build Page 11 entries |
| Award Write-up Generator | Draft award write-ups |
| OSMEAC Generator | Structure an OSMEAC order |
| AAR Generator | Write an after-action report |
| Restriction Tracker | Track restriction periods |
| Screening Package Builder | Assemble screening packages |
| T&R Tracker | Track training and readiness events |

Naval letters are handled by the [Naval Letter Generator](https://github.com/jeranaias/navalletterformat).

## Offline use

Open the site once, then use **Prepare All Tools for Offline Use** on the home page. Every tool works afterward without a connection.

Static HTML, CSS, and JavaScript. Nothing leaves your browser.
